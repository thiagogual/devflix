# devflix ⭐ FEATURED PROJECT

> **A Netflix-style streaming interface clone built for educational purposes. Features movie catalog, search, categories, and player interface.**
>

## 🚀 About This Project

A Netflix-style streaming interface clone built for educational purposes. Features movie catalog, search, categories, and player interface.

This project was developed as part of the DevClub ecosystem — one of Brazil's leading programming communities, founded by Rodolfo Mori.

## 🛠️ Technologies

- Node.js
- Tailwind CSS
- Vite

## 📦 Installation

```bash
git clone https://github.com/thiagogual/devflix.git
cd devflix
npm install
```

## ▶️ Usage

```bash
npm start
# or
npm run dev
```

## 🏗️ Architecture

- Frontend: React + TypeScript/JavaScript
- Styling: Modern CSS / Tailwind CSS
- Build Tool: Vite
- Backend: Node.js / FastAPI (when applicable)
